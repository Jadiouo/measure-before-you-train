# L2/L3 預測（跑之前寫）：哪些格子最佳規則對上界差距 > 2%

全部是推論；L2/L3 程式尚未寫完執行。只讀過 L1 說明與結果。
掃描：N{5,10}、V、實際設定、f_ind=0.4、c{1,10}、個體差異{0,15%}；L2 雜訊 = 無 / 獨立 σ{5,15,30}% / AR(1) 相關長度{10,50} x σ{5,15,30}%，事件 p{0,0.2}（共 20 種擾動）x 8 = 160 格。L3 = 局部氣泡規則，看 σ{0,15}%。
上界 = 事後全知（hindsight）LP，是寬鬆上界（知道每架每步的雜訊），所以 L2 的差距是「規則 + 上界鬆度」，不全是 RL 可拿的空間。

## 先驗
- L1：實際設定、f=0.4 的差距都 < 1.5%（c=10 最大）。雜訊使各架整趟累積耗電有 sigma_eff 的隨機差，等於額外的個體差異。
- 獨立雜訊整趟平均掉：1000 步、σ=30% 只剩 ~1% 的累積差，≈ L1 的 ±1.7% 個體差異；L1 在小個體差異就 <1.5%。
- 相關陣風 L=50、σ=30% 累積差 ~9–10%，且規則只能事後從剩餘電量看到；這是線上適應問題。
- 事件（p=0.2，中途某架 +20%）≈ 該架多耗 ~10% 的總電量，規則只能事後發現。

## L2 預測（最佳規則 = 沿用閘門 / 預估閘門 / 固定 / 時間輪 中最好者；對 hindsight 上界）
1. 獨立雜訊（σ 全部）：差距 < 2%，除了 h=0 的 c=10 格可能 ~2%（沿用 L1 同質 c=10 弱點）。最大 ~2.2%。
2. 相關陣風 L=10：與獨立相近，< 2%；σ=30% 可能 1.5–2.5%。
3. 相關陣風 L=50：σ=5% < 2%；σ=15% 邊緣（1–2.5%）；σ=30% 在 c=10 多半 > 2%（2–5%），c=1 約 1–2.5%。
4. 事件 p=0.2：與雜訊疊加，> 2% 集中在 c=10 且 σ≥15%；p=0 vs 0.2 差約 0.5–1.5 個百分點。
5. 全 160 格：約 15–25% 的格子（24–40 格）最佳規則 > 2%，集中在 AR L=50 x σ≥15% x c=10 x N=10。N=10 比 N=5 多。
6. 預估閘門 (EMA) 比沿用閘門在相關陣風與事件格好 0.3–1 個百分點；在獨立雜訊與 σ=0 格不好或持平。
7. σ=0、p=0、全域資訊：回到 L1（閘門範圍與 L1 的 gate 完全相同，上界與 L1 的 LP 相同）。

## L3 預測（局部氣泡規則，從無排序的初始排列開始）
8. 局部規則損失（相對全知閘門）：h=0.15 時 1–6%（要靠相鄰換位把 5–10 架排好，c=10 時排序的換位成本壓過收益）；h=0 時 N=5 約 1–3%、N=10 約 2–8%（輪轉只在鄰機之間，深位置的飛機換不到領頭）。
9. 局部規則對上界差距 > 2% 的格子：L3 的 σ∈{0,15%} 各 16 格（N x c x h x 事件），預測 > 60% 的格子 > 2%，N=10 與 c=10 幾乎全部 > 2%；N=5、c=1、h=0 少數 < 2%。
10. 把局部規則的初始排列換成已排序（消融）後，損失降到 < 1.5%：大部分損失來自初始排序成本，不是動態規則。
11. 推論：L2 的獨立雜訊沒有 RL 空間；若有空間在相關陣風 / 事件 x c=10；L3 是最有可能有空間的一層（資訊受限造成的損失 > 2%）。
