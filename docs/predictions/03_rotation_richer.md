# L1 預測（跑模型之前寫）：哪些格子裡 (d) 排序規則 與 (f) 流體最優 差距 > 2%

全部是推論，L1 的程式尚未執行；寫這份之前只讀過舊模型結果與馬蹄渦說明檔。
格子 = N{3,5,7,10} x 隊形{V,梯隊} x 位置設定{實際,最佳} x f_ind{0.3,0.4,0.5} x c_swap{0,1,3,10} x 個體差異{0,15%,30%}，共 576 格。
「最佳規則」= 每格在 (a)-(e) 中取航程比最高者。差距 = (最優 - 規則)/最優。

## 先驗
- 有效節省 = f_ind x scale x (1 - D_i/D_solo)，量級約 0.1-0.25，和舊模型 s=0.1-0.3 同級；但跟飛位置之間有 0.02-0.08 的差距，舊模型沒有這一層。
- 舊結果：兩級模型裡電量閘門與最優差 0-2.2%；時間輪的差距主要來自不看個體差異。
- 位置之間節省只差幾個百分點，所以「多層」帶來的額外空間有限；個體差異（15%、30%）遠大於位置差異，仍是主要驅動。
- 流體上界的換位成本只算「每架到過幾個不同位置」，會低估真實換位數（尤其 c 大時），所以我預期上界在 c=10、N 大時偏鬆，把差距墊高。

## 預測
1. 個體差異 +-0%：最佳規則（預期是時間輪，τ 約 D/N）對最優差距 < 2%，全部 144 格中至多 3 格破（c=10、N>=7、最佳設定、f=0.5）。
   (d) 單獨在 c>=3 可能 2-3%（會為了 rd 的微小差別抖動換位）。
2. +-15%：最佳規則差距落在 1-5%。> 2% 集中在 f=0.5 或 0.4、最佳設定、N>=5、c>=3 的格子，約 30% 的格子破 2%。
   實際設定（o=0, dx=3b，位置間差異小）與 f=0.3 的格子大多 < 2%。
3. +-30%：差距更大，約 45% 的格子破 2%，最大值 5-8%，出現在 N=10、梯隊、最佳設定、f=0.5、c=10。
4. 全 576 格合計：最佳規則 > 2% 的格數約 30%（區間 15-45%）。(d) 單獨 > 2% 的格數比最佳規則多約 5-10 個百分點。
5. N=3 V 形只有「領頭 / 兩個等價跟機」兩級，等同舊模型，預期最佳規則（電量閘門）< 2%（所有 c<=3 的格子）。
   梯隊 N=3 有三級，略大於 V。
6. 維度趨勢：差距隨個體差異、f_ind、位置設定從實際到最佳、c 單調上升。隨 N 的趨勢不確定：舊模型是隨 N 下降，這裡位置層數隨 N 增加，兩股力量互相抵消，我預期不單調。
7. 最佳規則預期是 (d) 或 (e)（成本感知）在個體差異格子；同質格子是 (b) 時間輪。閘門 (c) 在 N>=5 因為只能換領頭，用不到深位置，預期輸給 (d)/(e) 0.5-2 個百分點。
8. 結論預測：多數格子 < 2%，不值得上 RL；值得的是 +-15/30%、f_ind 大、最佳設定、c>=3 的區塊。
9. 錨點（所有跟飛位置節省相同）：新模擬器與舊 drone_bucket.simulate 在固定、時間輪、閘門三條上航程比相同到浮點誤差；新 LP 與舊 MILP 在 c=0 時相同，c>0 時因我改了換位成本記帳（出場也付尾流損失），可能有 < 0.5% 差異。
