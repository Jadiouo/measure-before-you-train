# L3 缺口的 MAPPO 驗證：事前宣告（凍結於任何 MAPPO 在 L3 格子上的結果之前）

日期 2026-11-04。這份檔案 commit 之後，判準、格子、預算、閾值不再改；要改另開新檔。標「推論」者是判斷。

## 0. 問題與已看過的東西（誠實前提）

問題：只看局部觀測的分散式 MAPPO 策略，能不能補回「局部規則」和「全域規則」在 L3 留下的差距？
已知（calib/out/drone_bucket_l23.json，notes/impl/drone_bucket_l23.md）：在上界可信、rot 差距 >2% 的 23 格（20 格是 N=5、noise=ar、h=0），min(rot, local) 對上界差 1.73–3.82%，全域規則（gate／gate_est）差 0.69–1.71%，逐格差 0.52–2.17 pp（中位 1.41）。**這 23 格是依 rot 差距挑的，有選擇偏差。**
已看過的 MAPPO 結果：只有接線除錯用的 ≤20 次更新、尚未學會任何東西的跑（格子 N5_ar50_s0.15_p0.0_c10_h0.0；貪婪評估平均航程比 1.00589 = 不換位基線，取樣評估 1.019 比 local 的 1.0469 差）。沒有任何訓練過的 L3 結果被看過。
規則參數是在同一批 200 個實例上取最佳的（對規則樂觀，對 MAPPO 保守）。

## 1. 環境與介面（程式：scripts/drone_l3_jax.py，與 numpy 版逐實例比對）

- 動力學是 scripts/drone_bucket_l23.py `simulate` 的逐行 JAX 移植；位置表、雜訊、事件、實例全用原模組產生（不重寫）。tests/test_drone_l3.py 在 float64 下，對 4 個格子 × 7 條規則（fixed、rot 240／20、local 三種參數）、24 個實例，證明移植版與原版航程比最大差 <1e-9。
- 決策每 5 個模擬步一次（t%5==0, t>0；local 規則 τ∈{5,10,20}、rot 的 τ 全是 5 的倍數，所以規則都能表示）。一個決策塊 = 套用決策（那一步是換位步，耗電與規則完全相同）+ 5 步模擬。
- 動作（每架）：0 不動；1 與後方鄰機（位置 p+1）交換（只有 p<N−1 且兩位置倍率差 ≥0.003 才有效，與 local 規則相同）；2 全隊輪轉（只有位置 0 的領頭機能下，等於 rot 規則的動作）。衝突：輪轉 > 成對交換；成對請求由位置 0 起貪婪接受。
- 獎勵：全隊每塊的航程增量 /B0（團隊獎勵，γ=1；總和 = 航程比）。回合到任一架電量歸零為止。

## 2. 觀測

- **Actor（分散式，所有飛機共用一個 MLP 2×64 tanh）**只拿 L3 允許的局部資訊：自己與鏈上鄰機（位置 p−1、p+1）的剩餘電量、rem/k、rem/(k·ρ)（ρ = 自己觀察到的耗電倍率 EMA，α=0.05，與 local 規則 α=0.05 版相同）、k、自上次參與換位以來的步數，自己的位置（one-hot）與兩側位置倍率差，鄰機存在旗標，奇偶旗標（決策計數 %2）、全域時鐘 t/1000。
- 與 local／rot 規則的資訊關係：local 規則用的是「相鄰一對的 rem/k（或 EMA 版）與位置倍率」，rot 只用時鐘；兩者的輸入都是上述觀測的子集（推論：「自上次換位步數」讓 MLP 能近似 rot 的週期，所以策略類別含 rot 與 local 的近似）。Actor 的觀測是 L3 允許的上限（含兩側鄰機），略多於 local 規則實際用的；沒有任何全隊資訊（不看非鄰機的電量、不知道 N 以外的全域排序）。
- **Critic（集中，CTDE）**：MLP 2×64 tanh，輸入全隊狀態（依位置排列的每架 rem、rd_est、ρ、k、自上次換位步數）+ 時鐘 + 全隊自上次換位步數 + 奇偶；輸出一個全隊價值。訓練時才用，評估只用 actor。
- 實例：訓練時每次更新隨機產生新的實例（雜訊、事件由 PRNG 在線產生，同一雜訊分佈）；評估時用 JSON 當時用的那 200 個實例（同 numpy 種子、同雜訊、同事件）→ 與規則**逐實例配對**。評估用貪婪（argmax）動作；取樣動作的結果也記錄，不作判準。

## 3. 格子選擇

三組，全部 h=0（同質）、N 取自原 JSON：
- **A（23 格，依 rot 差距挑出）**：JSON 中上界可信（`opt_timeouts==0` 且 `opt==opt_incumbent`，98 格）且 `rules.rot.gap`>2% 者。N=5 有 21 格、N=10 有 2 格。這組檢驗「有餘裕的地方補不補得回」，但有選擇偏差：rot 差、剛好被選上的格子，會讓 min(rot,local)−gate 的差距看起來比一般格子大。
- **B（14 格，不是依 rot 挑出）**：同一個 JSON、上界可信、N=5、h=0，扣掉 A 的全部格子（沒有抽樣，是該條件的全部）。理由：A 的反面，用「同 N、同 h 的所有其他可信格」，不經任何規則結果挑選；這 14 格的局部規則差距多數 <2%（0.35–1.87%），多半沒有餘裕，預期補不補都看不出來，是用來檢查「結論是否只在被挑出來的格子成立」。其中 2 格（noise=none、p=0）是確定性單一實例，沒有實例變異，只有種子變異。
- **CTRL（3 格，取自 A，只用於正向對照）**：N5_ar50_s0.15_p0.0_c10_h0.0、N5_ar10_s0.3_p0.0_c10_h0.0、N5_ar50_s0.05_p0.0_c1_h0.0（局部 2.09–3.82%、gate 0.69–1.65%）。
- 完整格子名單由 scripts/l3_cells.py 從 JSON 重新算出（A、B 由程式決定，不手挑）。
- h=0.15 的格子**不納入**：全域規則本身只差 0.0–0.5%，局部規則差距的來源是初始排序而非動態（drone_bucket_l23.md 第 1 節），沒有 gate−local 的差距可補。N=10 且 h=0 的上界逾時格不可信，不納入（A 中的 2 個 N=10 格上界可信）。

## 4. 正向對照（sanity gate）：沒通過就不解讀 L3 結果

目的：證明這套 MAPPO（程式、超參數、規模）在**已知有改進空間**的設定下學得起來。
- 設定 **MAPPO-G**：同一環境、同一演算法與超參數，但 (i) actor 多兩個全域特徵（領頭機的 rd_est 與其他飛機最大 rd_est 的差、全隊自上次換位的步數）；(ii) 領頭機多一個動作 3「閘門換位」（與 rd_est 最大的飛機互換，即 gate 規則的動作；何時換由策略學）。已知這個策略類別含有 gate 的近似，且 gate 在 CTRL 三格比 min(rot,local) 好 1.4–2.2 pp。
- 指標：F_G = 〔R_MG − R_L〕/〔R_gate − R_L〕（R 為 200 個配對實例上的平均航程比；R_L = rot 與 local 中平均航程較高者；R_gate = JSON 的 `best_global`），3 個種子取平均。CI 見第 6 節。
- **通過條件**：3 個 CTRL 格中至少 2 格的 F_G（種子平均）≥0.5 且 95% CI 下界 >0。
- 訓練預算階梯（事先固定，只在控制格上階梯式決定）：U ∈ {500, 1000, 2000} 次更新（每次 256 個回合）。先跑 U=500，沒通過再跑 U=1000，再沒通過跑 U=2000；仍沒通過 → **L3 結果一律「無法判讀」，不跑 L3 正式，停下來問〔作者〕**；不得為了通過而改超參數、獎勵、網路（要改另開新預先登記）。通過的最小 U 即為 L3 正式跑的 U。
- 限制（事先承認）：MAPPO-G 每 5 步決策一次，numpy 的 gate 每步決策，MAPPO-G 略吃虧；正向對照用的是比 L3 多資訊的 actor，只證明「優化器、獎勵、網路規模」夠用，不證明 L3 actor 在所有格子都學得好。為此另設一條 L3 內部的底線：L3 格子中，MAPPO 種子平均航程若低於「不換位（fixed）」規則超過 0.005（0.5 pp）→ 該格標記為「訓練失敗」；若 >30% 的格子被標記 → 無法判讀。被標記的格子仍照實算進 F（不排除）。

## 5. 主要指標與判讀

每格 c：R_M,c(i) = 種子平均的 MAPPO 貪婪航程比（實例 i）；R_L,c(i) 同上（局部規則 = rot 與 local 中該格平均航程較高者，用 JSON 的最佳參數，重算結果必須等於 JSON `range`，程式已驗證）；R_G,c(i) = JSON `best_global` 規則。
- 逐格補回比例 F_c = mean_i(R_M−R_L)／mean_i(R_G−R_L)。
- 集合補回比例（**主要指標**）F_S = Σ_c mean_i(R_M,c−R_L,c) ／ Σ_c mean_i(R_G,c−R_L,c)，S ∈ {A, B}（A 含 2 個 N=10 格；同時報 A 只含 N=5 的 21 格）。
- 次要：MAPPO 對上界的差距 gap_M = 1 − mean(R_M[前 60 個實例])／`opt`（與規則同一算法，只用有 LP 的 60 個實例），列出 A 中 gap_M ≤2% 的格數，對照 min(rot,local) 的格數；逐格 F_c 的中位數（只含 R_G−R_L ≥0.005 的格）；各種子單獨的 F_S（看種子散布）。
- CI：兩層 bootstrap 2000 次：重抽格子（可重複）→ 在每個被抽中的格子內，重抽實例（與規則配對，確定性格子不重抽）與重抽種子 → 重算 F_S；取 2.5%／97.5% 百分位。種子數 3（訓練種子 0、1、2，key=100·seed+7），評估實例 200（確定性格 1），訓練/評估實例不重疊（訓練在線產生）。

判讀（以 A 為主、B 為檢查）：
- **前提**：第 4 節正向對照通過，且被標記「訓練失敗」的格子 ≤30%。且 A 的分母 Σ(R_G−R_L) 的 CI 下界 >0（全域規則確實比局部好；否則無「差距」可補）。前提不成立 → 無法判讀。
- **補回**：F_A ≥ 0.5 且 F_A 的 95% CI 下界 >0，並且 F_B 的 CI 下界 >0（B 上不是反向）。
- **部分補回**：F_A 的 CI 下界 >0 但（F_A <0.5 或 B 不滿足上式）。
- **沒補回**：F_A 的 CI 上界 <0.5 且 CI 下界 ≤0（含 0）。
- **無法判讀**：前提不成立；或 CI 同時含 0 與 0.5（解析度不足）；或完成的種子 <2/3。
- 補充（不改變上述判讀）：A 是選擇出來的，B 才是不依規則挑選的；若 A、B 結論不同，兩個都如實寫，不合併。

## 6. 我的預測（跑之前）

- 正向對照：U=500 通過 35%；U≤1000 通過 65%；U≤2000 通過 75%。（推論：gate 的動作很稀疏，PPO 要學到「差距超過 δ 才換」需要夠多回合。）
- L3：MAPPO-L 大多重新發現 rot（領頭機每 ~160–240 步輪轉）而不是比它更好；F_A 點估計 **0.15**（80% 區間 −0.15 到 0.45），F_B 約 0.05。判讀機率：沒補回 40%、部分補回 25%、補回 10%、無法判讀 25%。A 的 N=5 21 格裡，MAPPO 的 gap_M 仍 >2% 的格子 ≥15 格。
- **打臉條件**：(a) F_A 的 CI 下界 ≥0.5（我低估了局部學習）；(b) F_A ≤ −0.1 且 CI 上界 <0（學出來的策略比規則還差 → 優化問題，不是資訊問題）；(c) 正向對照在 U=500 就通過且 F_G ≥0.9（我高估了難度）；(d) B 上 F_B 的 CI 下界 >0.3（我以為 B 沒有餘裕可補）。

## 7. 算力預算與停損

- 實測（CPU，本專案 .venv，JAX CPU）：N=5、256 個回合/次更新約 **1.5 s/更新**（〔已遮蔽：本機資源設定〕），N=10 約 3.6 s/更新。GPU 〔已遮蔽：本機資源設定〕。
- 預算（工作量以「更新次數×格子×種子」算，U 由正向對照決定）：
  - 正向對照：3 格 × 3 種子 × U（階梯最壞累計 3500 次更新/run）。U=500 約 1.0 CPU-h；階梯跑到 2000 累計約 5.3 CPU-h。
  - L3 正式：37 格（A 23 + B 14）× 3 種子 = 111 run，每 run U 次更新。U=1000 時約 N=5 的 105 run × 25 min + N=10 的 6 run × 60 min ≈ **50 CPU-h**；U=500 約 25 CPU-h；U=2000 約 100 CPU-h。
  - **上限**：總計 ≤ 60 GPU 小時（若在 CPU 上量，以 CPU 小時等量計，CPU 需另徵得同意）；單一工作 ≤6 小時（每個工作是一串依序的 run，6 小時內切斷）；〔已遮蔽：本機資源設定〕。超過上限即停下來問，不自行加碼。
  - 超預算時的縮減順序（事先固定）：先砍 A 的 2 個 N=10 格；再砍 B 中 p_event=0.2 的格；仍超預算則停下問。不得改種子數以下的判讀門檻。
  - 停損：正向對照階梯跑完 U=2000 仍沒通過 → 停；L3 任何 U 下單 run 出現 NaN 或 eval 回合未結束（NB=300 塊不夠）→ 停並查，不續跑。

## 9. 限制（事先承認）

- 只涵蓋 h=0、N=5 為主；3 個種子；MAPPO 在被規則最佳化到同一批 200 實例的格子上比較（對規則樂觀）。
- 動作空間（相鄰交換＋輪轉）是我選的；其他局部通訊協定（兩步外鄰機、帶記憶的規則）沒有試。「沒補回」只對這個策略類別與這個預算而言。
- Actor 看到的是 L3 觀測的上限（含兩側鄰機）；若補回，不代表只需 local 規則資訊。
- 上界是寬鬆的 hindsight 上界（知道每步雜訊），MAPPO 與規則都達不到；gap_M 是對該上界。
