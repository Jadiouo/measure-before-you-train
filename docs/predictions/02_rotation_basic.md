# 預測（跑模型之前寫）：哪些格子裡 (2) 時間輪退尾 與 (4) 最優 差距 > 2%

差距 = (最優航程比 − 時間輪最佳 τ 的航程比) / 最優航程比。全部是推論，沒有跑過任何程式。

模型細節的先驗：換位那一步參與者失去尾流（這本身就是成本，即使 c_swap=0）；退到隊尾的輪換有 N 架參與，所以 c_swap>0 時它比「兩架對調」貴。

1. 個體差異 ±0%（同質）
   - c_swap = 0、1：差距 < 2%（約 0.5–1.5%）。成本只有換位當步失去尾流與 τ 離散化的不均。
     唯一可能破 2% 的是 s=0.3 且 N=10 的格子。
   - c_swap = 3：臨界，約 1–3%；N≥7 與 s≥0.2 較可能 > 2%。
   - c_swap = 10：多數格子 > 2%（約 3–8%），因為 N 架全參與，每次換位全隊付 10·s。N=3 例外，可能仍 < 2%。
2. 個體差異 ±5%：N≥5 時全部 > 2%（約 3–9%，N 越大越大）。原因是時間輪不看 k_i、B_i，等於吃到最差那架；
   最優能用領頭時間補償。N=3 時 s=0.1 可能 < 2%（領頭時間能補償的量上限約 s）。
3. 個體差異 ±15%、±30%：幾乎所有格子 > 2%，且 > 5%。s=0.1 時最優也補不完，但時間輪更差，差距仍大。
   差距隨 N 與個體差異單調上升。
4. 結論的預測：「多數設定下差距 < 2%」不成立。真正 < 2% 的只有同質且 c_swap ≤ 1 的格子，約占全部 192 格中 1/8 以下。
   所以這題對規則式「時間輪」不是太簡單；但電量閘門 (3) 預期在 c_swap ≤ 3 時與最優差 < 2–3%，
   即「看得到 k_i 的規則式就夠了」，RL 的空間主要在看不到 k_i 的隱藏係數版本。
5. 隱藏係數版（只比 (2) 與 (3 用估計值)）：若耗電量測無雜訊，估計一步就準，(3) 幾乎不退化；
   有 10% 雜訊時退化小（< 1–2%），仍優於時間輪。
