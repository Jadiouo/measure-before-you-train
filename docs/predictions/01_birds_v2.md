## 1. 環境與條件

- `path_T=2.0` s（v1 為 3.0；單次換位成本 0.455 vs 0.869 P_solo·s；選 2.0 的理由：最短的「無擦撞」值，≤1.5 s 時鄰鳥最近距離 <0.8 b 且 LLC 追不上，見 `calib/out/swap_cost_pathT.json`）。`t_lock=8 s`、`delta_h=2 s` 不變。
- `surv_obs_abs=True`（觀測的能量欄用全隊共同分母 `E_ref=ε·P_solo·T`，h 的起始差與個體差看得見）。
- `surv_pw_spread=0.05`、`surv_pw_fixed=False`（每隻鳥每回合重抽耗能乘數 U(0.95,1.05)；選重抽的理由：actor 共享參數、不看身分，固定乘數與編號綁定沒有意義，重抽迫使策略從能量讀取差異）。

## 3. 判準
沿用 `survival_mappo_prereg.md` 並以 v2 基準取代，**CI 改 seed 層級**（k=3，t(0.975,2)=4.303，對 3 個 seed 的各自數值取 t 區間）。
- **維持**：最後十分位訓練換位率 ≥0.01/s，**且**最終評估報酬 ≥ 0.9622 + 2×該 run 的回合 CI95。
- **塌縮**：最後十分位訓練換位率 <0.005/s。**中間**：其餘。換位率取訓練 log 的 `swap_rate`（取樣策略）；報酬為取樣策略評估。
- 條件成立的計法：3/3 seed 符合預測＝「成立」；2/3＝「多數」；≤1/3＝「不成立」。
- **能量感知（新）**：僅對「維持」的 run 評估，指標＝上表最後一欄（接手者為三者最高能量的比例），取評估的 512 回合；三鳥存活換位事件 <100 次 → 記「無法判定」。
  - 每個 run：≥**0.50** → 能量感知；≤**0.40** → 能量盲；之間 → 中間。（0.50 約為 rot30 的 0.345 與 gate 的 0.65 的中點；0.40 高出 rot30 約 0.055。）
  - 條件層級「能量感知顯著」＝ ≥2/3 的維持 run 為能量感知，**且** seed 層級均值的 t 區間下界 > 0.345（rot30 的對應值）。不滿足但均值 >0.40 → 寫「傾向」，不寫「顯著」。
  - 輔助（不單獨決定）：被換下的領頭是三者最低能量的比例（rot30 0.398、gate30s 0.678）；報酬對 rot30 的配對差（同 512 初始狀態），seed 層級 t 區間。
- 報酬對照只報區間：A2−隨機、A2−rot30、A2−gate30s（seed 層級）。

## 4. 預測（跑之前寫死；信心標在後面）
- **A2（MAPPO α=1）維持，≥2/3（多數）**。v1 的 A 在 1e8 維持 3/3，但 s1 餘裕小；這裡只訓 5e7、環境不同，所以門檻放在「多數」。信心中。
- **A2 能量感知顯著**（≥2/3 的維持 run 為能量感知）。依據：能量差現在看得見，且 gate 比 rot30 高 +0.04（約 4 個 CI），有梯度可學；反方：v1 的 A 在能量欄只有 e_min_other 的差異時也沒學到（0.53），可見能量不保證學到，且 gate 需要「等到接棒者能量更高才交棒」的條件式行為。信心低（約 40%）。
- **B2（IPPO α=1）塌縮，≥2/3**（v1 的 D 3/3 塌縮；換位變便宜可能軟化，預測不變）。信心中。
- **C2（IPPO α=0）塌縮，≥2/3**：小賽局顯示等分輪替在 α=0 邊緣格是 NOT_EQ（最佳偏離 +0.02～+0.03），能量感知輪替雖為弱均衡，但 IPPO 無從發現。信心中高。
- **D2（MAPPO α=0）不維持（維持 ≤1/3）**。v1 的 α=0.5 MAPPO 已中段塌縮。信心中。
- 不預測：α=0.5。

## 5. 解讀規則（事先寫明）
- A2 成立（或多數）＋B2 成立 → 「α=1 時集中式 critic 防止塌縮」在 v2 環境再得到 3 seed 支持（推論：機制為信用分配）。
- A2 維持但**能量盲**（維持 run 皆 ≤0.40）→ 「看得見體力差仍學不到依能量分工」成立：瓶頸不是觀測，而是探索或信用分配（推論）；不得寫「環境缺資訊」。
- A2 維持且**能量感知顯著**，且報酬 > rot30（seed 層級下界 >0）→ 可宣稱「集中式 critic＋可見能量差可學到能量條件式輪替」，限定邊緣格、N=3、3 seed。
- C2／D2 出現維持（≥2/3）：若能量感知 → 支持小賽局「α=0 下能量感知輪替可為弱均衡」（推論，且僅 EQ_EPS）；若能量盲 → 與小賽局矛盾（等分輪替預測為非均衡），需另開機制說明（例如環境隱含的互惠）。
- 全部條件都塌縮 → 換位變便宜與可見能量差都不足以讓輪替出現，回到 v1 的結論，不再追加模型修改而先檢查優化。
- 報酬高於隨機僅少數百分點時只報區間，不報顯著性（v1 慣例）。

## 6. 限制（事先承認）
- 僅邊緣格、N=3、3 seed；MAPPO 與 IPPO 的差異含 critic 結構與輸入資訊兩項（v1 消融顯示解耦 critic 只有 1/3 維持，弱支持）。
- 閾值 0.50／0.40 與 path_T=2.0、乘數 ±5%、重抽的選擇，是在看過腳本基準與小賽局之後定的；乘數幅度 ±5% 是〔作者〕指定，不是量測。
- 5e7 步，不排除更長訓練後塌縮或學到能量感知；v1 A 用 1e8，這裡的 5e7 讓 A2 與 v1 的 A 不可直接比較步數效應。
- 能量感知指標在三鳥存活的換位事件上計算，維持但換位很少的 run 可能「無法判定」；gate 的 0.65 上限由環境結構決定，達不到 0.65 不代表沒學到。
- 小賽局只檢查一次性偏離族；gate 規則門檻（接棒者能量 > 現任）未調參。
