# 滑翔餘裕測試第三輪（最後一次拆解）預測

寫於任何正式評估之前。我已看過第二輪結果（L2-L1 = +3.2 到 +13.9 pp），預測依設計與機制推論寫，不是依第三輪數字。

## 設定
- 程式 scripts/soaring_headroom3.py（import 第二輪的 simulate2 / 世界模型，第二輪檔案不改）。8 格、世界（H0=1600、HMAX=3200、低雜訊、T=2400）、N=5 全跑、N=10 跑 mid|long|W3、sparse|long|W1.5、mid|short|W1.5。評估種子 0-59，調參種子 1000-1023，分開；L1、L2 以同樣種子與流程重跑，配對。閘門 Emin（pp）。
- L1.5a = L2 的決策結構（指派用分數；環圈中依「目前爬升率」離開，每 5 s 判斷），所有數值只用全隊觀測：
  - 強度 = 最近一次量到的爬升（環圈中用自己的變壓計 EMA 即時更新，繞完一圈的平均也更新），再依先驗壽命 exp(-年齡/Lbar) 衰減；
  - 目前爬升率 = 自己的變壓計濾波值（wf，EMA alpha=0.3）減下沉；
  - 中心 = 進入偵測時用當下位置，之後每圈用量到的質心；漂移 = 風（L1 本來就用世界的風向量，視為可由地速量到，L1 與 L1.5a 相同）。
  - 沒有任何真值（不含熱氣流強度、中心、年齡、壽命）。
  - 調參預算與 L1 相同：基底參數（th_leave, shgain, lv, use_roll, th_det）沿用 L1 的調參結果，再用 GRID_SHARE 12 組（kappa, Uexp, mc）調參；th_ref 固定預設 0.2。
- L1.5b = L1 的決策結構（繞完一圈平均才決定離開、weak/top/mc 規則），belief 的中心／強度／漂移換成已偵測熱氣流的真值（同 L2 的資訊）。同樣 GRID_SHARE 12 組。
- 判讀規則（寫死）：「MARL 有證據空間」需 (1) L2-max(L1.5a, L1.5b) 的 95% 區間下界 >2 pp，且 (2) 非地板格（L1 落地率 <0.5）至少 3 格符合；否則「此設定下 MARL 無證據空間」。L1.5a 追回大部分差距 -> 「更好的手寫規則」，報新規則；L1.5b 追回大部分差距 -> 資訊差。「大部分」= 點估計 >= 一半的 L2-L1。

## 預期（Emin，pp，N=5）
| 項目 | 預期點估計範圍 | 預期有幾格下界 >2（8 格） |
|---|---|---|
| L1.5a - L1 | -2 到 +5 | 1-3 |
| L1.5b - L1 | +1 到 +9 | 3-5 |
| L2 - L1（重跑，應重現第二輪） | +3 到 +14 | 7 |
| L2 - max(L1.5a, L1.5b) | -1 到 +4 | 0-2 |

- 機制推論：L2 的增益多半來自「真目前強度」讓離開時機準確（資訊），所以 L1.5b（資訊但舊結構）應追回約一半以上；L1.5a 的離開判斷靠有雜訊的濾波值，會較差，可能因抖動離開而低於 L1 在長壽命格。L2 對兩者的最大者仍會有 0-4 pp 的餘量（需要同時有真值和新結構），但區間下界 >2 的格數預期 0-2，非地板格 >=3 格的機率約 12%。
- 地板格（L1 落地率 >=0.5）：預期仍是第二輪那 4 格；非地板 4 格是 mid|long x2、mid|short|W3、sparse|long|W3。N=10 方向同 N=5。
- 結論預測：「此設定下 MARL 無證據空間」機率約 85%；L1.5a 追回大部分差距（成為新最佳手寫規則）機率約 20%；L1.5b 追回大部分差距機率約 60%。
