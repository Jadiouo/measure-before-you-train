# 滑翔餘裕測試第二輪（資訊對等）預測

寫於正式評估之前。誠實聲明：程式寫完後做過兩次小規模 smoke（--quick，網格縮成 1/4、一次 mid|long|W3、一次 sparse|long|W1.5，N=5，只為確認不當機與計時）；我有看到輸出的大致數字，但下面的預測是依設計與先驗寫的，沒有據此調整。正式評估使用完整網格。

## 設定
- 程式 scripts/soaring_headroom2.py（import 第一輪的世界模型與規則 scripts/soaring_headroom.py，第一輪檔案不改）。
- 避免落地地板的辦法：起始高度與上限都加倍（H0=1600、HMAX=3200，T 仍 2400 s）。理由：只加倍起始高度會貼著上限；加倍 T 則算力加倍。滑降不找熱氣流可撐 1600 s，Amin 地板由 0.33 變 0.67。
- 主指標（閘門）Emin = 全隊最低那架的時間平均高度／HMAX（落地後算 0）。Amin、落地率照報。
- 格：{sparse, mid} x {short, long} x W/ws {1.5, 3} = 8 格，低雜訊（vario 0.15、翼差 0.05），N=5 全跑；N=10 跑 mid|long|W3、sparse|long|W1.5、mid|short|W1.5。通訊無限。每格評估種子 60（0–59），調參種子 24（1000–1023），分開；差距 = 種子配對 bootstrap 2000 次的 95% 區間，單位 pp。
- 階梯（皆為規則式智能體，一次只改一個變數；各層與規則同樣用 12 組網格調參，L1 基底參數由 N=1 的 120 組網格調出）：
  - L0 不共享；L1 共享規則（retune；若調參種子上共享沒贏就退回 L0）；
  - L2 ref_seen：全隊「已偵測」（有人進入圈飛）的熱氣流，以真實中心／強度／漂移取代信念，指派與留／走用真實強度的最佳化；未偵測的仍用規則搜尋與規則的定心位移；
  - L3 ref_seen + 完美定心（繞真實中心）；
  - zone：分區散開搜尋（每架一條橫帶，東西交替，帶在熱氣流座標系），其餘同 L1；
  - prior：依先驗密度與「上次掃過時間」計算的期望值選擇搜尋方向（16 個方向、折扣和），其餘同 L1；
  - plan：簡版後驗取樣規劃器。K=6 個後驗樣本（未知熱氣流 = 先驗密度 x 1-exp(-距上次掃過時間/先驗壽命) 抽點，強度與壽命抽自先驗），每 10 s 對每架搜尋中的隊員逐一評估 12 個方向 + 「保持航向」，在固定 rollout 長度 H（120 或 200 s）內以直線飛行 + 遇熱氣流圈飛的期望增益率打分；已被前一架選中路徑涵蓋的樣本熱氣流視為已認領；已知熱氣流用 L1 的評分比較後取最大。只用全隊觀測（共享信念）＋先驗。
  - ref：第一輪的地圖全知參考解（縮小網格重新調參），只當上方參照。
- 先驗擾動（只在規劃器對 L1 點估計 >1 pp 的格做）：密度 x2、x0.5、壽命 x2、x0.5。規劃器、L1、最強搜尋基準（zone／prior／L1 中調參種子分數最高者）都用被擾動的先驗重評。

## 判準
- C1：規劃器 − L1 的 Emin 區間下界 >2 pp（格內）。額外報 C1'：規劃器 − 最強基準 的下界 >2 pp。
- C2：C1 成立的非地板格 >= 3（地板格 = L1 落地率 >= 0.5 的格，其差距不計）。
- C3：先驗擾動四種裡 C1 仍成立（規劃器 − L1 下界 >2 且對最強基準點估計 >0）於至少 3 種，且在 C1 成立的格中多數如此。
- 「RL 有空間的證據」= C1、C2、C3 同時成立。規劃器輸或打平 = 「未決」，不是「沒空間」。止損：差距只出現在地板格 → 「此設定下 MARL 無證據空間」。

## 預期（N=5，Emin，相對 L1，pp）
| 項目 | 預期點估計範圍 | 預期有幾格區間下界 >2（8 格） |
|---|---|---|
| L1 − L0 | 長壽命 +2 到 +10；短壽命 −2 到 +2 | 3–4 |
| L2 − L1 | +2 到 +10（長壽命較大） | 5–7 |
| L3 − L2 | +1 到 +6 | 4–6 |
| L3 − L1 | +4 到 +15 | 6–8 |
| zone − L1 | −3 到 +3 | 0–2 |
| prior − L1 | −2 到 +4 | 0–3 |
| plan − L1 | −4 到 +4 | 0–2 |
| ref − L1 | +10 到 +35（主要是資訊差） | 8 |

- 地板格：預期 0–2 格（sparse|short 最可能）；Amin 在多數格 >0.9，落地率低，所以 Amin 差距通常 <2 pp，Emin 才分得開。
- N=10：方向同 N=5，L2 − L1 +2 到 +8，plan − L1 −3 到 +3。
- 規劃器：C1 在 >=3 格成立的機率我給 15%；C3 因此多半不會被檢驗。最可能的結論是「未決」（規劃器沒贏，但它是簡版）。L2/L3 對 L1 的差距是「定心／指派的空間」，不等於 RL 空間，因為它們的資訊（已偵測熱氣流的真值）比 L1 多。
- 結論預測：(i) 資訊對等且可達成的方法（zone、prior、plan）相對 L1 的增益 <2 pp 居多；(ii) L2/L3 的差距若存在，來源是量測噪聲與定心誤差（資訊量），不是決策結構。
