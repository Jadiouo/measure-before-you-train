# 預測（跑之前寫，先 commit）

模型尚未跑。條件 = 密度{稀,中,密} x 壽命{短,長} x W/ws{1.5,3} x 感測雜訊{低,高} = 24 組；N{1,5,10}；通訊{無限,中等,無}。
差距單位：主指標（全隊最低那架的在空時間比例）的百分點。門檻 2 pp。

## (a) 單機：參考解（知道熱氣流位置與強度）− 調好的規則
- 預測 >2 pp：稀疏與中密度的幾乎全部條件（約 16 組以上）。理由：參考解不用搜尋，規則要靠碰運氣找；這是「資訊的價值」，不是 RL 空間。
- 預測 <2 pp：密度最高、壽命長、W/ws=3 的條件（4 組左右，雜訊高低都是）。理由：到處都是熱氣流，規則一碰到就爬。
- 密 + W/ws=1.5：預測 >2 pp（熱氣流只剩邊際爬升，定心精度與離開判斷決定結果，參考解有完美定心）。

## (b) 多機共享規則 − 不共享規則
- N=5、10、通訊無限：預測稀疏與中密度、壽命長 >2 pp（約 8 組以上，各 N）。
- 壽命短（約 5 分鐘）：共享的資訊很快過期，預測增益縮小，稀疏短壽命可能 <2 pp。
- 通訊中等（2 km，世界 5 km）：預測增益比無限小，但仍多數 >2 pp 於稀疏/長壽命。
- 密度最高：預測 <2 pp。
- W/ws=1.5：共享增益小（熱氣流本來就難用），預測 <2 pp 居多。

## (c) 參考解 − 多機共享規則（MARL 最多能贏的空間）
- 預測 >2 pp 的條件：稀疏全部（參考解知道全部熱氣流，共享規則只知道有人撞到過的）、中密度短壽命、所有 W/ws=1.5 且雜訊高的條件。N=5 的差距 > N=10（人多覆蓋多）。粗估 24 x 2（N）= 48 格中約 55–65% 差距 >2 pp。
- 預測 <2 pp：密度最高 + W/ws=3 的條件。
- 推論：(c) 是上限，不是 MARL 的可達值，因為參考解擁有 RL 拿不到的資訊（全知位置），所以真正 RL 空間會比 (c) 小；我預期扣掉「資訊」之後，差距更小。

## 最佳規則（預測）
- 單機：定心有用（偏移步數 >0 勝過關閉）、離開門檻中等；高雜訊時用兩翼差訊號的優勢很小（<1 pp）。
- 共享：加上「更好的已知熱氣流存在就離開現在這個」（MacCready 型）有幫助；擁擠懲罰對結果幾乎無影響，因為模型沒有碰撞或容量限制。

## 錨點預測
- 無雜訊 + 密 + 長壽命 + W/ws=3：各法差距 <2 pp，參考解 ≥ 規則。
